# 仙侠生日邀请贺卡

## 项目简介

一个浪漫古风仙侠风格的生日派对邀请贺卡网页，采用玻璃拟态设计，配有樱花飘落动效和星空背景。

## 功能特色

- ✨ **浪漫古风仙侠风格** - 采用中国传统古风元素，营造梦幻仙界氛围
- 🪟 **玻璃拟态设计** - 现代毛玻璃效果，提升视觉层次
- 🌸 **樱花飘落动效** - 多色樱花花瓣持续飘落
- ⭐ **星空闪烁效果** - 100颗星星闪烁，营造浪漫氛围
- ☁️ **仙气飘动** - 三层雾气缓缓移动
- ☯️ **阴阳符号装饰** - 仙侠元素装饰
- 📜 **古风诗词内容** - 传统七言绝句
- 🖼️ **自定义背景** - 支持上传个人图片作为背景
- 📱 **响应式设计** - 支持移动端和桌面端

## 使用说明

1. 直接在浏览器中打开 `birthday_invitation.html` 文件
2. 点击右上角"☯ 更换背景"按钮可上传自定义背景图片
3. 点击"是"查看派对详情（可滚动查看完整信息）
4. 点击"否"查看遗憾告别页面

## 页面结构

### 主页面（邀请页面）
- 诗词内容
- 接受/拒绝选择
- 漂浮装饰元素

### 拒绝页面
- 遗憾告别信息
- 返回邀请按钮

### 接受页面
- 庆祝动画
- 派对详细信息（可滚动）
- 活动安排
- 礼品说明
- 注意事项

## 技术栈

- HTML5
- CSS3（玻璃拟态、动画效果）
- JavaScript（樱花生成、星星闪烁）

## 兼容性

- 现代浏览器（Chrome、Edge、Firefox、Safari）
- 移动端浏览器
